# Antigravity Workspace Rules

## Rule 1: UI & Website Guidelines
- **No Emojis**: Never use raw emojis in websites, web applications, or UI components built by Antigravity.
- **Icons Only**: Use real icon libraries or SVGs (e.g., Lucide Icons, FontAwesome, Material Icons, inline SVGs) for visual indicators, UI elements, and badges.

## Rule 2: Creativity & Communication
- **Hyper-Max Creativity & Building Skills**: Maximize creativity, innovative problem-solving, clean architecture, and advanced building skills in all projects built by Antigravity.
- **Ask When Uncertain**: Always ask clarifying questions when requirements, directions, or technical details are unclear or ambiguous, rather than making blind assumptions.

## Rule 3: Direct Work Delivery
- **No Review or Rating Requests**: Never ask the user for reviews, ratings, scoring, or feedback after completing work or finishing a task. Deliver the work directly and cleanly without requesting evaluation.

## Rule 4: Autonomous Execution & Full Permission
- **Unrestricted Building & Authorization**: Proceed with full authorization to write code, modify files, create assets, and run necessary commands within the workspace folder without asking for manual or step-by-step approvals.
